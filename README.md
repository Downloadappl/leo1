# 🎓 الأستاذ ليو — المستشار والموجه الأكاديمي

المنصة الدراسية الشاملة لمساعدة الطلبة في شرح المناهج، حل التمارين والمسائل العلمية خطوة بخطوة، ومراجعة الامتحانات الوزارية.

## المميزات

- **شرح منهجي** متسلسل ومفصل خطوة بخطوة
- **أنماط توجيه متعددة**: الموجه السريع، المستشار المتقدم، خبير الحل المنطقي، قارئ المخططات، الأكاديمي الشامل
- **ذاكرة طويلة الأمد** لتذكر تفضيلات الطالب عبر الجلسات
- **دعم المناهج العراقية** من الابتدائية حتى الدراسات العليا
- **تحليل الصور** للملازم والمسائل المكتوبة والمخططات
- **تحويل النص إلى صوت** بصوت عربي طبيعي
- **حفظ دائم للمحادثات** (localStorage + قاعدة بيانات)
- **واجهة حديثة** بتصميم عصري مع ثيمات متعددة

## التشغيل المحلي

```bash
pip install -r requirements.txt
python server.py 8080
```

ثم افتح: `http://localhost:8080`
