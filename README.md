# 🎓 LeoGPT — الأستاذ والمساعد الدراسي الذكي

منصة تعليمية متطورة مصممة لمرافقة الطلبة وفق معايير المنهج الدراسي العراقي من المرحلة الابتدائية وحتى الدراسات الجامعية والعليا.

![LeoGPT](frontend/app.js)

---

## ✨ المميزات الرئيسية

- **شخصية الأستاذ ليو الأكاديمية:** معلم وموجه عراقي يشرح بأسلوب خطوة بخطوة (المفهوم العلمي، القوانين والمعطيات، الحل النموذجي، التنبيه للأخطاء الشائعة).
- **التوجيه حسب المراحل الدراسية العراقية:**
  - المرحلة الابتدائية (الصفوف من 1 إلى 6 وزاري).
  - المرحلة المتوسطة (الصفوف من 1 إلى 3 وزاري).
  - المرحلة الإعدادية (العلمي، الأدبي، المهني / البكالوريا).
  - المرحلة الجامعية (المراحل 1 - 6 وتحديد الكلية والتخصص) والدراسات العليا.
- **التوجيه النحوي الدقيق:** مراعاة صيغ التذكير والتأنيث للطلبة بدقة عالية.
- **نماذج LeoGPT المتدرجة:**
  - `Leo 4o Mini` — افتراضي وفائق السرعة للمهام والاستفسارات اليومية.
  - `Leo 4o Pro` — النموذج الأذكى والأعلى قدرة، حل متقدم للمسائل وتحليل الصور والمستندات.
  - `Leo o1 (تفكير)` — تفكير رياضي ومنطقي عميق لحل المسائل المعقدة والاستنتاجات.
  - `Leo Vision` — خبير الرؤية البصرية، قراءة صور التمارين والملازم والمخططات.
  - `Leo Academic` — متخصص في التلخيص والأبحاث العلمية وجداول المقارنات.
- **شريط الاستماع الصوتي الذكي (ChatGPT Audio Bar):** تموج صوتي تفاعلي، إمكانية الإيقاف المؤقت، الاستئناف، أو الإلغاء بزر واحد.
- **تدفق ذكي للنصوص (Real-Time SSE Streaming):** كتابة تدريجية للإجابات للرسائل الجديدة مع سرعة استرجاع فورية للرسائل السابقة.
- **إدارة المحادثات:** تثبيت في الأعلى (📌)، إعادة تسمية، أرشفة، وحذف فوري.
- **جاهز للنشر على Vercel:** يعمل كـ Serverless Functions وموقع فائق السرعة.

---

## 🚀 التشغيل محلياً

```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل السيرفر
python server.py 8080
```
ثم افتح المتصفح على: `http://localhost:8080`

---

## ☁️ النشر على Vercel

المشروع يحتوي على `vercel.json` ومجلد `api/` مجهز للعمل مباشرة:
1. ارفع المشروع إلى مستودعك في GitHub.
2. توجه إلى [Vercel](https://vercel.com/) وقم باستيراد المستودع (Import Repository).
3. اضغط **Deploy**.
